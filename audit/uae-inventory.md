## 4. Technical findings

- **Canonical mismatch** on all 24 UAE URLs: declared canonical is http + non-www; the
  site is actually served on https://www. Homepage canonical has the same defect (known).
- **Duplicate variants**: 4 host/scheme combinations all return 200 for every UAE URL —
  duplicate content; only trailing-slash normalization (301) exists.
- **Sitemap.xml**: 60 URLs, all 2006-era (`http://www.huisjurist.nl/*.htm`, PDFs/DOCs),
  every lastmod 2006-07-13; **zero current pages, zero UAE URLs**.
- **robots.txt**: HTTP 200, default Joomla boilerplate, no Sitemap reference, does not
  block Googlebot or OAI-SearchBot.
- **Crawlability**: OAI-SearchBot and Googlebot both get **200** on the section index,
  a sample article, /kosten.html and /contact/; homepage returns 301 → /index.html
  (normal redirect, not blocked).
- **Historical value concentration**: Google value sits on the **section index URL**
  (ranked #1 on site: queries). Individual articles do not surface separately in
  `site:` searches — treat the index URL as the primary asset to preserve; keep all
  article URLs intact (no redirects/renames) pending the GSC traffic check (item 4).
